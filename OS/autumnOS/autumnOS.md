# autumnOS

autumnOS is the first ever inner OS in stellarOS.

## install & boot

- os download autumnOS
- os boot autumnOS

## apps

To install anything, open the app store, all the downloads are also the terminal programs. Apps are stored in the browser. 

To update an app you can just install it again from the app store and it'll update the app automatically!

## profile

in autumnOS you can create a profile in the bottom right of the screen! All data stays locally so your profile is privatly stored.
